Generator angka acak

Pilih satu ukuran rentang: 10 (00–09, 10–19, … 90–99), 100 (000–099, 100–199, … 900–999), 1000 (0000–0999, 1000–1999, … 9000–9999), atau 10000 (00000–09999, 10000–19999, … 90000–99999). Tiap rentang diambil angkanya sebanyak yang Anda ketik. Sumbernya Random.org (lewat API key Anda jika diisi), dengan cadangan generator acak aman milik browser.

Ukuran rentang

Pilih ukuran rentang dan jumlah angka, lalu tekan Generate.

Dengan API key, beberapa rentang diambil sekaligus dalam satu permintaan (maksimal 10.000 angka per permintaan). Kuota harian key Anda terbatas dan dihitung dalam bit: kira-kira 4 bit per angka untuk rentang 10, 7 bit untuk 100, 10 bit untuk 1000, dan 14 bit untuk 10000. Misalnya rentang 1000 dengan 6000 angka per rentang (10 rentang) memakai sekitar 600.000 bit, dan rentang 10000 sekitar 840.000 bit, keduanya lebih besar dari batas harian 250.000 bit. Jangan menaruh API key di file yang dipublikasikan: key diketik di halaman dan hanya dikirim ke api.random.org. Garis hijau berarti dari Random.org, garis oranye berarti dari browser.
