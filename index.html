Generator angka acak

Pilih rentang tetap (10, 100, 1000, atau 10000, dibagi jadi 10 rentang) atau tentukan rentang sendiri, misalnya dari 37 sampai 482. Sumbernya Random.org (lewat API key Anda jika diisi), dengan cadangan generator acak aman milik browser.

Jenis
Ukuran rentang
Angka tersimpan

Pilih jenis rentang dan jumlah angka, lalu tekan Generate.

Klik sebuah angka untuk menyalinnya. Tiap rentang punya tombol “Salin rentang” dengan pilihan jumlah angka dan pilihan acak (acak memilih dan mengacak urutan, baik untuk sebagian maupun semua angka). Angka tersimpan disimpan di browser ini, bukan di server, sampai Anda menghapusnya. Pengecualian angka tersimpan berlaku untuk rentang yang persis sama, misalnya 0–25. Dengan API key, beberapa rentang diambil sekaligus dalam satu permintaan (maksimal 10.000 angka per permintaan). Kuota harian key dihitung dalam bit: kira-kira 4 bit per angka untuk rentang 10, 7 bit untuk 100, 10 bit untuk 1000, 14 bit untuk 10000, dan sekitar 30 bit untuk rentang sampai 1 miliar. Jangan menaruh API key di file yang dipublikasikan: key diketik di halaman dan hanya dikirim ke api.random.org. Garis hijau berarti dari Random.org, garis oranye berarti dari browser.
